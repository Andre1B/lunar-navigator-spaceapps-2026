# Ocean Gardens: observed interaction and implementation review

Research checkpoint: 2026-11-14. This is a deep dive into **Greetings from Earth!!**, the 2023 **Galactic Impact Award** winner responding to the **Ocean Gardens** challenge. It is already present in the 2020–2025 inventory, so this report deepens that record rather than adding another winner. NASA’s [official winners announcement](https://science.nasa.gov/directorates/smd/2023-nasa-international-space-apps-challenge-announces-10-global-winners/) lists the team under Galactic Impact and describes its interactive NASA-data ocean visualization.

## Evidence and scope

The live [Ocean Gardens site](https://oceangardens.github.io/) and the matching [OceanGardens/oceangardens.github.io repository](https://github.com/OceanGardens/oceangardens.github.io) were observed. The repository describes itself as the 2023 global-winning submission, links to the live site and lists six UNICAMP students. Its `main` page showed 181 commits, 48 branches and no tags when read; this mutable branch is not established as the exact judging-weekend version. The official team page was reachable but its project tab failed to load its content, so its inaccessible material is not inferred.

The root [`LICENSE`](https://github.com/OceanGardens/oceangardens.github.io/blob/main/LICENSE) states MIT, copyright 2023 Daniel Yuji Hosomi. The nested app README is the default Create React App boilerplate. Its `package.json` identifies React 18, React Router, Framer Motion, `react-globe.gl`, Plotly React and Unity WebGL among a long dependency list. No repository was cloned, built, installed or executed. The live site’s own JavaScript did run in the browser as part of observing its actual interface; no repository scripts or downloaded competitor code were executed.

NASA is credited beside the globes, which identify the input imagery as 2022 data. Repository image filenames identify annual 2022 Aqua MODIS Level-3 products for chlorophyll (`chlor_a`), sea surface temperature (`SST`) and photosynthetically available radiation (`PAR`), with PNG scale images. I did not validate the displayed scientific claims or trace every asset to a license. The root MIT file establishes a repository license for covered material; it does not establish the license of each third-party package, image or data product.

## What transfers to Lunar Navigator

1. **Keep a question visible as exploration opens up.** Ocean Gardens names the topic first, then guides the visitor through one story, and only then offers the three-layer globe. Lunar can keep the direct question (“what changes if arrival is delayed?”) present while users inspect Sun, Earth and terrain; the existing landing experiment and simulator already do much of this.
2. **Make a layer switch explain itself.** In the globe view, each selected dataset replaces both the map texture and its explanation. For Lunar, keep an inspected Sun/Earth/horizon state and its caption tied to the same selected instant. This supports current follow/aim controls; it does not call for extra visualization modes.
3. **Sequence the explanation as cause → consequence.** The observed story moves from phytoplankton through oxygen and climate. Lunar’s matching sequence is selected place/date/height → body relative to the horizon → visible fraction and duration. The app’s existing four-step explanation is already a stronger task-specific fit than copying the ocean lesson’s long page.
4. **Pair a vivid model with a plain-language interpretation.** The textured globe attracts attention, while a nearby panel says which variable is shown, how to read colors and where the data came from. In Lunar, label lit terrain as illustrative brightness and keep the exact angular horizon result beside it. This protects the scientific boundary the current Surface Sky now documents.
5. **Offer the shorter path without making it the only path.** The two Home actions distinguish a complete and reduced journey. Lunar’s guided comparison can remain the short route while the open simulator stays available; the visitor should still reach the same transparent evidence and inputs.

These are design interpretations, not documented reasons for the judges’ decision. NASA’s award announcement confirms the award and summarizes the project; it does not publish individual judge comments. The existing Lunar work already covers much of the proposed transfer. No new mode is justified solely by this comparison.
