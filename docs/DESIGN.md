# Visual and experience specification

Human direction: NASA-adjacent blue/white/red, modern clean space typography, separate screens; immersive button hides UI and provides a return action. No imitation of protected NASA identifiers.

Concept reference: generated 14 November 2026, archived privately as epic tmp/lunar-ui-concept.png. One generation only to preserve quota. Design reference, never scientific evidence or a shipped asset. Built-in image tool prompt requested a 1440x900 clean dark lunar workspace, Overpass-like headings, blue/white/red palette, documented scientific controls and no NASA identifiers. Visible AI watermark is present in the reference.

Tokens: background #070c18, canvas #050911, surface #101a2b, text #f5f7fa, secondary #b2bfd2, line #2c3b53, blue #2e96f5, red #ef5258. Typography: self-hosted Overpass 400/600/700, Fira Code 400 for dates/numbers. Three-pixel component radii, thin slate rules, open editorial layout. No decorative card stack, fake telemetry or invented numerical proof.

Approved user revisions supersede the initial single-screen reference: Home, Guided Mission, Simulator, Compare, Evidence, Credits are separate routes. Every route is accessible immediately. Faithful/Free refer to simulation physics, not navigation permissions. The simulator has Explore space / Return to workspace (Escape). No mission completion lock.

Scientific corrections to the generated concept: Free Mode is independent body freezes, not merely a free camera; dates follow dataset coverage, not the invented concept date; no NASA standards/safety claim; globe texture is aesthetic, numerical horizon is separate; simulated charts never use the example bars in the generated image.
