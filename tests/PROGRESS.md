Cause: `controls.addEventListener("change", render)` (SpaceScene.jsx ~315) and `render()` calls `controls.update()` (~275) which fires `change` again whenever the camera/target moved, so render -> update -> change -> render recurses (stack: OrbitControls.render at SpaceScene.jsx:184 repeated; Matrix4.invert in camera.lookAt). `focus()` moves camera+target then calls render(), triggering it. The exception aborts the onChange handler so the `<select>` also does not reset to "Look at…" (value stays e.g. "moon"). Surface sky view is not affected (controls.update skipped). Fix: re-entrancy guard in render (`if(rendering)return;rendering=true;try{...}finally{rendering=false}`) or call controls.update() outside the `change` listener path.
